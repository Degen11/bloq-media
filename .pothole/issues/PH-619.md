# Build-output suite (the guard for the original nodejs18 runtime bug) silently skips in every CI run

Confirmed by detect-test: evidence holds: build.test.ts:13-16,39 skipIf(!hasBuild) on .vercel/output vc-config; ci.yml:34-38 runs npm test before npm run build, so both suites skip on a clean CI checkout. Header comment (line 4) documents the skip but not that CI never runs it, so documented route does not kill the cost claim; no trap matches.

Evidence:
- tests/build.test.ts:13-16
- tests/build.test.ts:39
- .github/workflows/ci.yml:34-38

Kind: flaky.

How to fix: Make the build-output tests run after the build in CI (a separate vitest run or project invoked after npm run build), and make them fail rather than skip when CI is set and the artifact is missing.
